📖 About the Project

This repository contains my personal portfolio website, developed as part of my CodeAlpha Web Development Internship.

The portfolio is designed to provide a central place to explore my:

- Technical skills
- Projects
- Certifications
- Education
- Internship experience
- Achievements
- Resume
- Professional journey

The website is built using HTML5, CSS3, and Vanilla JavaScript, with a focus on responsive design, modern UI, accessibility, smooth interactions, and a professional user experience.

🚀 Getting Started

To run the project locally:

1. Clone the repository

git clone https://github.com/furqanzubair209-cell/CodeAlpha_PortfolioWebsite.git

2. Navigate to the project directory

cd CodeAlpha_PortfolioWebsite

3. Open the project

Open "index.html" in your browser.

For the best development experience, use Visual Studio Code with the Live Server extension.

🌍 Deployment

Live Website
